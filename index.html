About System
GVSI NetPulse

This Progressive Web Application (PWA) is designed for real-time monitoring of Gallopvision Services Inc. (A Managed Service Provider of Converge ICT Solutions, Inc.), including NAPs, LCPs, OLTs, nodes, and backbone links. Note: The data presented in this application is sourced from Gallopvision's LNOC database.

Developed by:
Jeremy

Version 2.3.2 — What's New & System Updates:

  • Backbone Modal — Affected Links: Added Affected Links section in the Backbone Link Details modal, displayed as chips. Ready for multiple comma-separated links per ticket (up to 5+ links).

Version 2.3.1:

  • Mobile Responsive Stat Cards: Backbone stat cards now use a responsive 3+2 grid layout on mobile devices.
  • Mobile Link Chips Horizontal Scroll: Long link descriptions scroll horizontally on mobile for cleaner layout.
  • Mobile Table Layout Fix: Backbone table exempt from ultra-small card-view mode.
  • Link Chip Compact Styling: Reduced font size and padding for tighter display.

Version 2.3.0:

  • Backbone Summary Stat Cards: Added 5 summary stat cards at the top of the Backbone Links tab showing Total Links Affected, DWDM Low Power, DWDM Link Down, MPLS Low Power, and MPLS Link Down counts.
  • Backbone Empty State Landing Page: Clean landing page when no pending backbone incidents — green checkmark with "All Backbone Links Operational" and DWDM/MPLS status indicators.
  • Backbone Downtime & Aging in Modal: Added Downtime (Col N) and Aging Duration (Col X) fields to the Backbone Link Details modal.
  • Backbone Table Cleanup: Removed Downtime column from table view, aligned total links count to Aging column.
  • Residual Data Filter Fix: Excluded phantom rows from stale Links (Y) and Count (Z) values when source ticket data is deleted.

Previous Updates:

Version 2.2.0:

  • Backbone Links Module (New): Fully integrated Backbone Links monitoring tab that pulls real-time ticket data from the "Backbone Tickets" sheet — displays Province, Service Type (DWDM/MPLS), affected links as interactive chips, link count, and status with full modal details on click.
  • Backbone Modal Details: Added slide-up modal popup for each backbone ticket showing Province, Ticket No, Service Type, Status, Aging Duration, and Remarks in paragraph style for easy readability.
  • Backbone Service Transformation: Auto-transforms service labels — "NPE" is displayed as "MPLS" while "DWDM" remains as-is, providing cleaner and standardized service type identification.
  • Background Auto-Refresh & Prefetching: Backbone data refreshes every 10 minutes in the background, preloaded 7.5 seconds after initial app load, and instantly syncs when the app returns from minimized state.

Version 2.1.1:

  • OLT Impact & Client Tracking: Added real-time affected client count per ticket via backend LNOC sync, featuring a dedicated "Affected Clients" column and "Affected Clients (DOWN)" summary card.
  • Visual Status Distribution: Integrated a high-performance, pure CSS donut chart for OLT status breakdowns (UP, DOWN, Low Power, Uplink Down, Degradation) with exact counts and percentage indicators.
  • LCP Impact Summary Row: Streamlined top metrics and added a comprehensive bottom summary row displaying Total Clients Affected, Total Tickets, and Total LCPs without additional fetch latency.
