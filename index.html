About System
GVSI NetPulse

This Progressive Web Application (PWA) is designed for real-time monitoring of Gallopvision Services Inc. (A Managed Service Provider of Converge ICT Solutions, Inc.), including NAPs, LCPs, OLTs, nodes, and backbone links. Note: The data presented in this application is sourced from Gallopvision's LNOC database.

Version 3.2.1 — What's New:

  • OLT Affected Clients Fix: Fixed double-counting of affected clients when multiple OLTs share the same ticket — each OLT now shows its individual client count from NLZ OLT Report.
  • Per-OLT Client Lookup: Apps Script now reads Column AB (OLT names) and matches each OLT to its client count in NLZ OLT Report Column A — no more summing duplicates.
  • Modal Affected Clients: OLT modal now displays individual affected clients for the selected OLT.

Version 3.2.0:

  • Keyboard Shortcuts (New): Press R to refresh, 1-7 to switch tabs, Esc to close modal, ? for help.
  • Custom Date Range (New): Analytics dashboard now supports 7/30/90 day filters for trend analysis.
  • Comparison Mode (New): Week-over-week comparison view in Analytics — see trends at a glance.
  • PDF Export (New): Export any module table as PDF — click Export PDF button on each tab.
  • Modal Link-Chip Fix: Affected links in Backbone modal now wrap properly — no more text overlap on desktop and mobile.

Version 3.1.1:

  • Skeleton Loading (New): Shimmer placeholders replace spinner — professional loading state with animated skeleton cards and tables.
  • Clipboard Copy: Click any ticket number in modals (OLT, Node, Backbone) to copy to clipboard with toast confirmation.
  • Alert Thresholds: Auto-highlight rows and stat cards when incidents exceed thresholds — red for high alerts, yellow for medium.
  • Bottom Navigation (Mobile): Fixed bottom tab bar on mobile devices — native app feel with icons for each module.
  • Tab Animations: Smooth fade-in transitions when switching between tabs.

Version 3.0.0:

  • IndexedDB Offline Storage (New): Daily snapshots saved locally for offline-first experience — app works even without internet, with up to 90 days of retention.
  • Trend Charts (New): Line and bar charts showing historical trends — Incidents per Day, OLT Status Trend, Clients Affected Trend, and Aging Distribution using Chart.js.
  • Push Notifications (New): Firebase Cloud Messaging integration for critical incident alerts — browser notification when OLT goes DOWN or new backbone incidents appear.
  • DOMPurify XSS Protection: All dynamic user data from Google Sheets is now sanitized before rendering, preventing potential XSS attacks.
  • Notification Toggle Button: Bell icon in the header to enable/disable push notifications with one tap.
  • Daily Snapshot System: App automatically captures daily metrics from all modules and stores them in IndexedDB for trend analysis.
